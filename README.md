# Micronaut HTTP Client Core

[English](README.md) | [简体中文](README.zh-CN.md)

[`micronaut.http.client`](micronaut/http/client/module.norm) binds the `@Client` annotation, synchronous client entry points, and resource lifecycle of Micronaut HTTP Client Core 5.1.13. The [sample](samples/README.md) makes a real request to a local HTTP fixture.
